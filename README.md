# Bot 传话

让机器人替你主动联系别人：对它说「去问 xxx 在不在」「帮我告诉 xxx ……」「转告 xxx 一下」，它会自己找到人、把话带到，并在对方回复时转告你。

## 行为

- **找人**：群聊里按群名片/昵称/QQ号解析；不在群里则查好友列表（备注/昵称/QQ号）
- **选通道**（auto 规则）：
  - 对话发生在群聊且对方就在该群 → **先戳一下对方，再 @ 他说话**（戳失败自动退回只 @）
  - 其他情况 → **只私聊**（对方不是好友时无法送达并如实告知）
  - 工具参数可显式指定 `private` / `group` 覆盖
- **转告**：私聊传话后，若对方在窗口期内（默认 30 分钟）私聊回复机器人，会把回复内容简短转告给发起对话的会话
- 传话内容由模型按人格生成，插件只负责送达；单条超长自动截断

## 触发

对机器人说（任意会话）：

- 「去问 xxx 明天要不要一起副本」
- 「帮我告诉 xxx 我晚点到」
- 「转告 xxx 让他看群消息」

模型会调用 `contact_person` 工具；工具返回送达结果，模型再向你确认。

## 配置

| 键 | 默认 | 说明 |
|---|---|---|
| enabled | true | 总开关 |
| allow_everyone | true | 关闭后仅所有者会话（owner_session）和 AstrBot 管理员可触发 |
| owner_session | 空 | 所有者私聊会话（如 `napcat:FriendMessage:123456789`） |
| poke_first | true | 群里先戳再 @ |
| max_per_hour | 10 | 每小时主动联系次数上限（滑动窗口，0 = 不限） |
| max_message_chars | 200 | 单条传话最大字数 |
| relay_replies | true | 对方私聊回复后转告发起人 |
| reply_window_minutes | 30 | 等待回复的窗口（5~1440） |

## 依赖

- 纯标准库实现，无第三方依赖。
- 支持 QQ（aiocqhttp）全功能；网页测试台触发时也会经 QQ 通道送达。
